# claude-codex-workflow

Personal skills and agents used with [Claude Code](https://claude.com/claude-code) and [OpenAI Codex CLI](https://github.com/openai/codex).

- `claude/skills/` — Claude Code skills (`~/.claude/skills`)
- `claude/agents/` — Claude Code subagents (`~/.claude/agents`)
- `codex/skills/` — Codex CLI skills (`~/.codex/skills`)
- `codex/AGENTS.md` — Codex global instructions (`~/.codex/AGENTS.md`)
